Frequency API

This is a simple API that returns the allocation of a frequency in the Finnish radio frequency allocation table.

Hae, mihin radiotaajuus on Suomessa varattu.

Open search

Endpoints

Frequencies can be given in Hz, kHz, MHz or GHz.

/api/freq/<freq>

Returns the allocations of a frequency as JSON.

Example: /api/freq/433MHz

/frequency/<freq>

Returns the results in an HTML table.

Example: /frequency/433MHz

/frequency/<freq>/<width>

Returns matches with freq ± width.

Example: /frequency/2.4GHz/1GHz

/unique-allocations

Allocations that don't overlap with any others.

Example: /unique-allocations

/unique-allocations/<field>/<value>

Unique allocations filtered by a field. The value can be a comma separated list; results match any of them.

Example: /unique-allocations/Sub_band_usage/amateur,amateur-satellite
